# Contributing to Network Radio Player

Thank you for considering contributing! Here are some guidelines to help you get started.

## How to Contribute

1. **Fork** the repository.
2. **Create a feature branch** (`git checkout -b feature/your-feature`).
3. **Make your changes**, keeping code style consistent with the existing codebase.
4. **Test** on a real device if possible (or in a Linux environment with SDL2).
5. **Commit** with a clear message describing the change.
6. **Push** to your fork and open a **Pull Request** against the `main` branch.

## Code Style

- Follow PEP 8 for Python code.
- Keep lines ≤ 100 characters.
- Use descriptive variable names.
- Add comments for non‑obvious sections (e.g., hardware‑specific workarounds).

## Reporting Issues

Use the GitHub issue tracker. Please include:
- Device model and firmware version.
- Steps to reproduce the issue.
- Relevant logs (from `radio.log`).

## Feature Requests

We welcome ideas! Open an issue with a clear description and, if possible, a proposed implementation approach.

## Testing

Before submitting a PR, ensure that:
- The app starts without errors.
- Audio playback works.
- All buttons function as expected.
- The UI renders correctly on 640x480 and 720x480 screens.
